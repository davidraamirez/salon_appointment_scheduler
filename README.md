# Salon Appointment Scheduler

An interactive salon appointment scheduling system built with Bash and PostgreSQL.

Developed as part of the [freeCodeCamp Relational Database Certification](https://www.freecodecamp.org/learn/relational-database/).

## Overview

This project provides a command-line appointment scheduling system for a salon. It uses PostgreSQL to store customer information, services, and appointments.

## Project Structure

- `salon.sh` – Interactive Bash program for managing salon appointments.
- `salon.sql` – PostgreSQL database dump containing the project database.

## Technologies

- Bash
- PostgreSQL
- SQL
- Linux

## Features

- Interactive command-line interface.
- Customer registration and management.
- Salon service selection.
- Appointment scheduling.
- Customer and appointment data stored in PostgreSQL.
- Automated database interaction using Bash.

## Installation

Clone the repository:

```bash
git clone https://github.com/YOUR-USERNAME/salon_appointment_scheduler.git
```

Navigate to the project directory:

```bash
cd salon_appointment_scheduler
```

Make the script executable:

```bash
chmod +x salon.sh
```

Run the application:

```bash
./salon.sh
```
